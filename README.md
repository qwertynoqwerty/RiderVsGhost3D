# RiderVsGhost

Гоночный 3D-прототип на Unity с записью и воспроизведением собственного заезда. В первом заезде сохраняется движение автомобиля, во втором игрок соревнуется с призраком, повторяющим эту траекторию.

Проект выполнен как тестовое задание. Основной технический сценарий - записать движение, сохранить его между перезагрузками сцены и запустить повтор одновременно со вторым заездом.

## Возможности

- Два последовательных заезда: запись и гонка против призрака.
- Запись позиции и вращения автомобиля во время первого заезда.
- Повтор траектории призраком во втором заезде.
- Обратный отсчет, таймер гонки и номер текущего заезда.
- Обработка финиша, повтор игры и возврат в меню.

## Техническая реализация

**Стек:** Unity 6, C#, Rigidbody, Cinemachine, Unity UI, TextMeshPro.

Запись и воспроизведение выполняются в `FixedUpdate` и разделены на два компонента. `RaceManager` управляет порядком заездов и передает записанные данные призраку. Траектория хранится в памяти между перезагрузками сцены; сохранение повторов в файл не реализовано.

| Код | Назначение |
| --- | --- |
| [GhostRecorder.cs](Assets/Scripts/Gameplay/GhostRecorder.cs) | Запись списков позиций и вращений |
| [GhostPlayer.cs](Assets/Scripts/Gameplay/GhostPlayer.cs) | Последовательное воспроизведение записи |
| [RaceManager.cs](Assets/Scripts/Gameplay/RaceManager.cs) | Старт, таймер, финиш и переключение заездов |
| [Loader.cs](Assets/Scripts/Gameplay/Loader.cs) | Переходы между сценами |
| [SimcadeVehicleController.cs](Assets/Scripts/Car/SimcadeVehicleController.cs) | Используемый контроллер автомобиля |

Механику повторов можно изучить отдельно от управления автомобилем: начните с `GhostRecorder` и `GhostPlayer`.

## Запуск

1. Откройте проект в Unity 6000.0.58f2.
2. Откройте сцену **MenuScene** и нажмите **Play**.

## Как играть

Запустите первый заезд из меню, дождитесь отсчета и пересеките финиш. После перезагрузки трассы начнется второй заезд с призраком. Завершите его, чтобы открыть итоговую панель.
